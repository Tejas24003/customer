# Customer Segmentation Using K-Means

A Python-based machine learning project that groups customers based on their age, annual income, and spending behavior using the K-Means clustering algorithm.

### Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

### Features

* Add customer data.
* Upload CSV files.
* Perform K-Means clustering.
* Visualize customer segments.

### Installation & Run

```bash
pip install -r requirements.txt
streamlit run customer_segmentation_app.py
```
